# ⏰ 每日规划（Time Planner）

拖拽式横排时间轴，可视化管理每日作息。

## 快速开始

```bash
cd time-planner
node sync-server.js
```

浏览器打开 **http://127.0.0.1:19831**

## 功能

### 📊 横排时间轴
- 24 小时从左到右排列，当前时间红竖线始终居中
- **3 条轨道**，卡片自动分配到不重叠的轨道
- **双击**空白处快速创建规划
- **拖拽**卡片移动时间，**拉伸边缘**调整时长
- **跨轨道拖拽**：拖着卡片移到其他轨道即可

### 📋 卡片式规划
- 每张卡片 = 一段规划，左端=开始时间，右端=结束时间
- 卡片宽度就是时长，完全可视化操作
- 支持启用/禁用、编辑、删除
- 5 种颜色 + 自定义分类

### 📋 列表视图
- 按时间排序的规划列表
- 支持启用/禁用、编辑、删除

### 📅 日期筛选
- 按周几筛选查看
- 每个规划可设置生效日期（工作日/周末/每天）

### 💾 本地存储
- 数据存储在 `routine.json`（本地文件）
- 通过 sync-server 读写，浏览器 localStorage 作为离线缓存

## 操作说明

| 操作 | 方式 |
|------|------|
| 新建规划 | 双击轨道空白处 / 点击「+ 新建」按钮 |
| 移动规划 | 拖拽卡片左右移动 |
| 调整时长 | 拖拽卡片左/右边缘 |
| 跨轨道 | 拖拽卡片到其他轨道 |
| 编辑 | 悬停卡片点击 ✏️ |
| 删除 | 悬停卡片点击 🗑 |
| 启用/禁用 | 悬停卡片点击 ⚡ |

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 前端页面 |
| `sync-server.js` | 后端服务（Node.js，端口 19831） |
| `routine.json` | 规划数据（自动同步） |
| `schedule.json` | 旧版提醒数据（已弃用） |

## 数据格式

```json
{
  "routine": [
    {
      "id": "r-xxx",
      "activity": "工作",
      "start": "10:00",
      "end": "11:30",
      "color": "orange",
      "category": "工作",
      "days": [1, 2, 3, 4, 5],
      "enabled": true,
      "overnight": false
    }
  ]
}
```

## 技术栈

- 前端：纯 HTML/CSS/JS，无依赖
- 后端：Node.js HTTP server
- 存储：本地 JSON 文件
