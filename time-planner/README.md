# ⏰ 时间规划器

管理你的时间段，到点自动提醒。

## 使用方法

编辑 `schedule.json` 添加你的规划，格式：

```json
{
  "plans": [
    {
      "id": "唯一ID",
      "date": "2026-05-18",
      "start": "09:00",
      "end": "10:30",
      "activity": "做什么事",
      "reminder": 15,
      "done": false
    }
  ]
}
```

- **date** — 日期（YYYY-MM-DD）
- **start / end** — 开始和结束时间（24小时制）
- **activity** — 要做什么
- **reminder** — 提前几分钟提醒（默认15）
- **done** — 完成后标记为 true

## 提醒机制

每15分钟自动检查一次，到时间会发消息提醒你。

你也可以直接告诉忘语「帮我安排明天9点到10点半学英语」，我会帮你添加。
