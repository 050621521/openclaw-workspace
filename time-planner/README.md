# ⏰ 每日规划

管理每日作息，可视化时间线，按分类统计时间。

## 快速开始

```bash
cd time-planner
node sync-server.js
```

浏览器打开 **http://127.0.0.1:19831**

## 功能

### 📊 时间线
- 24 小时时间线视图，直观展示每日安排
- 点击空白区域快速创建规划
- 支持跨天规划（如睡眠 23:00-07:00）

### 📋 列表
- 按时间排序的规划列表
- 支持启用/禁用、编辑、删除

### 📈 统计
- 按分类汇总每天的时间分配
- 进度条直观对比各分类占比
- 选周几就统计当天数据（不汇总整周）

### 📌 插入规划
- 中途插入新规划，后续自动推后
- 不用手动调整全天时间

### 📅 日期筛选
- 支持按周几筛选查看
- 每个规划可设置生效日期（工作日/周末/每天）

### 🏷️ 分类
- 规划可设置分类（工作、学习、生活、运动、休息等）
- 统计页按分类汇总时间

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 前端页面（浏览器打开） |
| `sync-server.js` | 后端服务（数据读写） |
| `routine.json` | 规划数据（自动同步） |
| `schedule.json` | 旧版提醒数据（已弃用） |

## 数据同步

- 启动 `sync-server.js` 后，页面自动从服务器加载数据
- 每次增删改规划，自动保存到 `routine.json`
- 数据同时缓存在浏览器 localStorage（离线可用）
